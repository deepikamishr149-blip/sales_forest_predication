# Sales Forecast Prediction Project

## Project Overview
This project predicts future sales using Machine Learning.
The model analyzes historical sales data and forecasts upcoming sales trends.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Random Forest Regression
- Streamlit
- Matplotlib

## Dataset
The dataset contains:
- Order Date
- Amount
- Profit
- Category
- State
- City
- Customer Details

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Sales Forecasting
7. Streamlit Dashboard

## Model Performance
- Algorithm: Random Forest Regressor
- R2 Score: 75.53%
